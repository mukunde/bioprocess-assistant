Method: `mabselect-documentary-handoff-corrected-freeze-v01`.

1. Verify the lock identity, fixed policy, declared roots, complete transitive
   file set and every LF-normalized SHA-256. Missing files, modified files,
   dropped inventory entries and policy promotion fail before runtime creation.
2. For execution, require the recorded CPython version and standard library only.
   No package resolution, installation, cache preparation or API is permitted.
3. Read the unchanged accepted SX01–SX06 requests and expected projections. Keep
   original product/context ownership and stable task IDs; no case-ID routing.
4. Construct the existing `Handoff(preview=True)` with the frozen defaults:
   65,536 context bytes, 32,768 request bytes and eight tasks maximum. This is
   explicit staging for checks; `Handoff()` remains inactive by default.
5. Run each request once without retries or reference-driven selection. Check
   expected status/item states/bundle keys, zero procedure cards in clarification,
   target fields, task isolation, exclusions and rejection before unauthorized
   lookup. Check task-bound context references, canonical context byte count and
   the absence of supported numerical pressure values.
6. Resolve every returned citation through this staging snapshot. Require exact
   equality of the delivered source object, available status and original quote
   hash. Required warnings, conditions and review reservations remain in the
   actual saved responses; no derived dosage or suitability is introduced.
7. Check the freeze again after assembly and reject any attempted socket operation.
   Preserve complete output only after success, using exclusive file creation.

The method lock excludes itself and replay outputs to avoid circular hashes.
It includes this method, the README, user decision, verifier and regression-test
source. Transitive review/preparation manifests include every real file read by
the selector's Q/N verification. Historical replay digest entries are assertions
about archived states, not requests for absent private raw files.

The frozen inventory contains no v03 engine modification, PDF, environment,
tokenizer asset, pilot, video, deployment, secret or private machine path.
`replay-results.json` is an independently retained output, not an admissibility
authority. Compare a fresh replay's canonical responses/digests with that record
when checking reproducibility; an intentionally changed method needs a new version.

The first replay is a known-case conformance check, not prospective or independent
answer-quality evaluation. Existing historical gates/scores are not amended.
