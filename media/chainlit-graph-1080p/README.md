# Graph chat recording

The 27-second silent recording shows a real Chainlit request for “High column
pressure” and the citations rendered from the Neo4j results. The local session
used Anthropic Claude Sonnet 4.6 and the seeded graph. The cited references
include the Cytiva antibodies handbook and the MabSelect SuRe data file.

Chrome ran in native fullscreen at 1920 × 1080 with 125% browser zoom. The
edit shortened the wait and held on the citations. The poster is a frame
from the final MP4.
