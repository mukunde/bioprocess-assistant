# Final storyboard

Audience: a recruiter unfamiliar with bioprocessing. Goal: understand the problem,
the useful action and the source-verification boundary without sound.

| Time | Scene | Purpose |
| --- | --- | --- |
| 0–5 s | Problem | An illustrative technical manual creates information overload. |
| 5–9 s | Purpose | Introduce the local evidence explorer and its bounded scope. |
| 9–17 s | Guided request | Identify the product, 1 mL format and washing operation, one focus at a time. |
| 17–24 s | Source | Show the real E121-W quotation and PDF page 121. |
| 24–30 s | Limits | Distinguish clarification from quarantined information. |
| 30–34 s | Outro | Project identity and visible music credit. |

Edited real UI DOM, not continuous interaction or an LLM demonstration. The manual
drawing is illustrative. The example serves 25 reviewed excerpts, not an entire
manual or a scientifically validated operating procedure. No voiceover is needed.
