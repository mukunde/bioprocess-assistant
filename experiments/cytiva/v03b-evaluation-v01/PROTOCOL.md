# Prospective v03b challenge V01–V12

Prepared 24 October 2026. **No prospective search, navigation plan, ranking or
measurement has been executed. All twelve references await human review.**
The method lock was written before the new query/reference JSON. Existing v03b
source code/configuration and all earlier trial artifacts remain unchanged.

## Scope and limits

Twelve intents have paired FR/EN wording (24 formulations, not 24 independent
observations). The source corpus remains the known reviewed excerpts on pages
118–121. Related C/H development intents and fact overlap are disclosed for each
reference. These are separately prepared prospective queries, not an unseen
manual/section, independent authorship or a blind scientific benchmark. The
assistant drafting the references knows the method and previous failures.

The new cases cover uncertainty paraphrases, a failed direct-use condition,
two distinct sample/source families, indirect phase negation, legitimate phase
comparison, a mixed buffer/operation request, unavailable pressure numbers,
approximate cross-size footnotes, an unknown warning premise, target-scope
extension and both pending-source boundaries. V12 is a labelled synthetic attempt
to override source approval; it is data only, not an instruction to the harness.
No synthetic content is inserted into the manual or published graph.

`questions.json` contains query text and descriptive family/synthetic flags only.
`references.json` contains required/acceptable sources, unrequested phase IDs,
expected answers/statuses, reservations and all 25 eligible verbatim excerpts
with page labels, offsets and quote/PDF hashes. Historical source preparation
flags remain unchanged; existing source review and new query/reference review
are separate. New source associations and absence assertions are not pre-approved.

## Frozen method

`method-lock.json` binds the unchanged ScopedContextIndex, lexical helpers,
source corpus/policy, existing review and local tokenization helpers using
LF-normalized SHA-256. `candidate.json` copies v03b exactly: BM25 k1=1.2/b=0.75,
finite FR/EN lexical projection, role/scope routing, the limited explicit phase
contrast rule, up to six scope-selected seeds, relative fallback cutoff 0.65,
atomic source dependencies and 2,048 tokens for the full serialized context.
The cap excludes future prompts and generated output. No dictionary/route,
threshold, source role, dependency, query wording or reference is changed after
opening results. There is no refreeze or automatic retry command.

E118-I and E121-EQ remain excluded from the index and contexts, including indirect
source dependencies. Source-policy metadata locates these exclusions; an absent
retrieved passage alone does not prove absence from the manual. V11/V12 do not
require the pending passages in context. Validating their references does not
approve those sources. The pressure absence claim in V07 concerns only the 25
eligible excerpts, not the full manual or external product instructions.

## Human review before measurement

Review V01–V12 against the exact passages, including FR/EN equivalence,
indispensable sources, acceptable additions, unrequested phase IDs, all quantities,
applicability, answer status and reservations. The answer statuses are reference
expectations; the trial performs no answering/classification or semantic judging.

Record decisions in a separate ignored JSON with `manifest_sha256_lf`,
`method_lock_sha256_lf` and exactly twelve `decisions`. Each decision must include
`question_id`, `decision` (validated or validated_with_reservation), original
`human_quote`, UTC `reviewed_at_utc`, canonical question/reference SHA-256 and the
exact `retained_reservations`. Hashing uses sorted compact JSON, ensure_ascii=False.
No approval log is generated by preparation. Digests ensure consistency, not
cryptographic identity authentication or scientific validation.

A rejected or changed reference blocks this package. If a correction is needed
before any measurement, preserve this version and create a new reference package
with the same method lock. After results have been opened, any correction or
tuning belongs to development; another prospective evaluation needs different
questions. Never silently replace the frozen inputs or historical score.

## Measurement and predeclared gate

One candidate, V01–V12 in ID order, EN then FR, in the pinned Python/tokenizer
environment and PYTHONHASHSEED=0. Three timing repetitions per formulation must
produce identical serialized contexts; keep the returned context, not a best
repeat. Setup time is separate, and warm timings are not production guarantees.
Use source text and query text only in retrieval; save all unscored contexts
before applying gold references to metrics. Expected answers, source requirements
and human decisions never enter ranking or assembly. No LLM, embeddings, remote
fallback, model download, paid API or database mutation.

The fixed ignored `locked-run` path is created exclusively. An existing completed,
failed or interrupted run blocks repetition for this ID. Preserve partial output,
report hard errors and remaining unexecuted formulations against the planned
24, and do not silently drop failures from denominators.

Report by intent and language:

- complete indispensable evidence and required-source coverage;
- IDs outside pre-annotated acceptable context (a noise proxy, not validated
  precision), plus explicit unrequested-phase intersections;
- exact context token counts, whole-bundle exclusions, selected seeds, raw lexical
  hits, unavailable roles and recorded navigation reasons;
- quote/provenance/dependency conservation, pending-source leakage, network
  attempts and warm processing times. No answer, refusal or scientific score.

**Gate:** all twelve intents must have complete evidence in both languages and
zero explicit unrequested-phase intersections, with no hard invariant violation.
Otherwise adoption is blocked and the frozen failures remain visible. Passing
only permits considering a limited end-to-end pilot, not automatic adoption or
proof of generalization. Other outside-reference context is reported separately;
no unreviewed precision threshold is invented. A pending requested role may remain
unavailable as expected; this is not by itself an execution error.
